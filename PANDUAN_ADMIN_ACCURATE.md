# Panduan Install Aplikasi Perdina Marketing Intelligence
## untuk Admin Accurate Online

### Yang harus dilakukan (±2 menit):

**Langkah 1 — Buka link install**

Buka link berikut di browser (login pakai akun **Admin** Accurate Online):

```
https://account.accurate.id/marketplace/user/application/install-confirm.do?appKey=aa1e2e93-63f4-4410-beca-7a2d811c0f34&databaseId=1814259
```

**Langkah 2 — Konfirmasi install**

- Login ke Accurate Online (akun yang punya hak Admin)
- Halaman akan menampilkan konfirmasi install aplikasi **Perdina Marketing Intelligence** untuk database **PT. PERDINA INDO UTAMA**
- Klik **Install** / **Confirm** / **Ya**

**Langkah 3 — Beri akses ke user lain (opsional)**

Setelah install, admin bisa memberi akses ke user lain:
1. Buka **Accurate Online** → **Settings** → **Manajemen Pengguna**
2. Pilih user yang akan diberi akses (misal: **Masiah Masiah**)
3. Pastikan user tersebut memiliki akses ke database **PT. PERDINA INDO UTAMA**
4. **Centang izin** untuk modul yang diperlukan:
   - ✅ Penjualan (Sales)
   - ✅ Persediaan (Inventory)
   - ✅ Pelanggan (Customer)
   - ✅ Barang (Item/Product)

**Langkah 4 — Beri akses Marketplace ke user (opsional)**

Jika user tetap tidak bisa connect setelah install:
1. Buka **Accurate Online** → **Settings** → **Manajemen Pengguna**
2. Pilih user → klik **Edit**
3. Di bagian **Akses Marketplace**, pastikan user bisa mengakses aplikasi **Perdina Marketing Intelligence**
4. **Save**

---

### Troubleshooting

| Masalah | Solusi |
|---|---|
| "Anda memerlukan Hak Administrasi" | Login pakai akun **Admin**, bukan akun biasa |
| User tidak bisa connect setelah install | Pastikan user punya akses ke database PT. PERDINA INDO UTAMA |
| Database tidak muncul di app | Pastikan sudah install + user sudah login ke akun yang benar |
